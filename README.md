# Kostadinov_et_al_2026_LearningFast-slow

Analysis code associated with Kostadinov, Clark and Hausser (2026) Fast and slow learning mediated by distinct climbing fiber signals

## System requirements:
- All analysis was done in Matlab 2024a on a PC running Windows 10. No non-standard hardware should be required to run analysis.
- GLM fitting was done using the Matlab implementation of Glmnet. Details on installation and compiling cam be found here: https://hastie.su.domains/glmnet_matlab/download.html.
