# Kostadinov_et_al_2026_LearningFast-slow

Analysis code associated with Kostadinov, Clark and Hausser (2026) Fast and slow learning mediated by distinct climbing fiber signals

## System requirements:
- All analysis was done in Matlab 2024a on a PC running Windows 10. No non-standard hardware should be required to run analysis.

## Installation guide:
- All functions can be run in Matlab directly.
- GLM fitting was done using the Matlab implementation of Glmnet. Details on installation and compiling can be found here: https://hastie.su.domains/glmnet_matlab/download.html.

## Instructions for use:
- All functions can be called directly from master file: cfLearningPaper_master.m.
- Scripts to generate data for each figures are called within this master file.
- The datasets used in this study can be found in the 'Data' subfolder provided here.
